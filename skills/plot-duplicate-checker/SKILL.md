# 剧情重复检测器

## 角色

作为长篇网文节奏控制专家，检查最近章节是否存在重复桥段、重复爽点和重复情绪循环。

## 输入

```json
{
  "recent_chapters": [
    "第31章概要",
    "第32章概要"
  ]
}
```

优先分析最近 10 章；少于 10 章时按已提供内容分析。

## 检测内容

重点检测：

1. 剧情重复。
2. 爽点重复。
3. 情绪重复。
4. 打脸重复。
5. 财富刺激重复。
6. 旁观者震惊重复。
7. 对手挑衅方式重复。
8. 主角解决问题方式重复。
9. 章末钩子类型重复。

## 重复风险判断

- 低：重复桥段少，情绪和冲突有变化。
- 中：同类爽点连续出现 2 到 3 次，但仍有主线推进。
- 高：连续多章使用同一套压迫、打脸、震惊、收尾结构。

## 高重复时的切换方向

如果重复率过高，必须建议切换到：

- 感情线。
- 危机线。
- 阴谋线。
- 成长线。
- 身份曝光线。
- 失败风险线。
- 资源争夺线。

## 输出格式

```json
{
  "重复风险": "高",
  "问题": [
    "连续财富打脸",
    "连续旁人震惊"
  ],
  "重复模式": "对手质疑→主角亮数字→众人震惊→对手闭嘴",
  "建议": [
    "切换感情线",
    "增加危机",
    "增加失败风险"
  ],
  "下一阶段替代桥段": [
    "让主角短期失去关键资源",
    "让女主发现主角隐藏身份的异常",
    "让资本方暗中设局"
  ]
}
```
