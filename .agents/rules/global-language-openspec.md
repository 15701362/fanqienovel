# Agent 全局规则

## 对话与回答语言

1. 所有对话与回答必须使用**简体中文**（书面语以大陆常用表述为准）。
2. Always reply in Simplified Chinese.（与上条一致，作为英文界面下的重复强调。）

## OpenSpec Skill 文档

3. 所有 **OpenSpec skill** 相关文档产出（包括但不限于 skill 说明、步骤、示例、表格、模板正文）必须使用**简体中文**；代码标识符、文件路径、URL、专有名词原文可保留，但解释与说明须用简体中文。

## Git 提交信息

4. 所有 Git 提交信息必须使用**简体中文**，包括提交标题和必要的提交正文。
5. 提交标题应简短明确，优先使用“新增、修复、调整、删除、重构、文档”等中文动词开头。

## 例外（按需）

- 用户明确要求使用其他语言时，以用户当次指令为准。
- 用户提供的引文、法规原文、第三方英文材料需逐字引用时，可保留原文，并辅以简体中文说明。
